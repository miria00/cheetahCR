\section{Limitations, Future Work, and Broader Impact}\label{app:limitations}
CHEETAH is a new mathematical abstraction for global HW/SW co-design.
It exposes tile choice, tensor residency, rematerialization, fusion and hardware provisioning to one linear program, so cross-stage trade-offs that sequential pipelines cannot express become ordinary variables of a single optimization.
We prove that the lifted sequential feasible set is contained in CHEETAH's, isolate a fixed-hardware free-$y$ gain on Llama-3 70B, and demonstrate a second strict separation on capacity-constrained DeepSeek-V3.
The decomposition of the speedups in Figure~\ref{fig:speedup}, up to $24.20\times$ on LLM prefill and $17.93\times$ on LLM decode, shows that the gain is not merely the result of adding MACs, and a rounded, simulated replay shows that the trade-offs are not an LP artifact.
This is the first formal and empirical demonstration that tiling-then-fusion loses solutions, paired with a joint method that recovers them and a certificate that says how far any schedule can still go.

The reported efficiency quantities are roofline-model diagnostics, not measured silicon utilization, and real implementations would still incur NoC, SRAM, pipeline and control overheads.
The certificate is relative to the declared implementation library and cost model, and the RTL evidence validates mechanisms rather than a fabricated chip.

CHEETAH turns co-design from a sequence of expert judgments into one reproducible optimization with a certified gap, and that abstraction reaches well beyond the inference accelerators studied here.
The same program can serve as an end-to-end design engine for new silicon and as an optimization engine for the hardware that already exists, and it opens questions that heuristic pipelines could not pose, from which architectural features a model family provably needs to what a new network should look like if it is to run well on the chips that exist.
Inference demand is growing far faster than general-purpose silicon improves, and every point of utilization and every watt that a certified co-design recovers is multiplied across billions of daily requests.
We see this work as the foundation for a broad program of certified HW/SW optimization across the full stack and lifecycle of machine learning systems.
